Student records are stored and organized with core data structures and algorithms.

[ ]

Arrays

A student array holds the roster. Add, edit, and delete actions update that collection.

Index access O(1)

Searching

Linear search checks all fields; binary search locates an exact ID in sorted data.

Linear O(n) · Binary O(log n)

Sorting

Stable merge sort organizes the directory by name, ID, program, year, or score.

Merge sort O(n log n)
